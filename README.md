# Dynamic B2B Marketplace Payment & Invoicing Automation

Automated B2B payment routing and dynamic multi-product GST invoicing system built for Zoho Commerce & Zoho Books.

## System Features
- **UPI Payments:** Dynamic QR generation with zero gateway commission fees.
- **RTGS/NEFT Transfers:** Flat-fee Virtual Account (Smart Collect) routing with 15-minute price locks.
- **Dynamic Invoicing:** Automated Deluge processing supporting any product, tax slab, or quantity.
